Most slow laptops we see in Pretoria are not broken. They are overloaded: too many programs starting with Windows, a drive that is almost full, or power settings that hold the processor back. Work through these checks in order. Each one takes a few minutes and needs no tools.

1. Restart it properly

Shutting down a Windows laptop is not the same as restarting it. With Fast Startup switched on, Shut down saves part of the system to disk so it can boot faster, which means some problems survive the shutdown. Restart clears everything. If your laptop has been sleeping and waking for weeks, a restart alone often makes a noticeable difference.

2. See what is using the computer

Press Ctrl + Shift + Esc to open Task Manager, then click the CPU, Memory and Disk column headings to sort by each one. Anything sitting near the top for minutes at a time is your suspect.

  • A browser with 30 tabs open is a common cause. Close the tabs you are not using.
  • If Disk sits at 100% for a long time, that points to the drive itself (see step 8).
  • If you do not recognise a program, search its name online before ending it.

3. Stop programs from starting with Windows

Many programs add themselves to startup when you install them: chat apps, updaters, game launchers, cloud storage. Each one slows down boot and keeps running in the background.

In Task Manager, open Startup apps (called Startup on Windows 10). Right-click anything you do not need the moment the laptop turns on and choose Disable. This does not uninstall it; you can still open it yourself when you need it.

Keep your antivirus and anything to do with your touchpad, sound or graphics enabled. If you are unsure about an item, leave it on.

4. Free up storage space

Windows needs free space to work. When the main drive is nearly full, everything slows down. Go to Settings → System → Storage to see what is using it.

  • Use Temporary files to clear update leftovers and the recycle bin.
  • Check your Downloads folder. It is often full of installers and videos you no longer need.
  • Move photos and videos to an external drive or cloud storage.
  • Uninstall programs you no longer use under Settings → Apps → Installed apps.

Aim to keep at least 15–20% of the drive free.

5. Check the power mode

Laptops save battery by slowing the processor down. On Windows 11, go to Settings → System → Power & battery → Power mode and choose Best performance while you are plugged in. Also make sure Battery saver is not switched on permanently.

6. Install updates, then restart

Open Settings → Windows Update, install what is waiting and restart. Updates fix bugs that cause slowdowns. A laptop that has been putting off updates for months can also be slow because it keeps trying to download them in the background.

7. Scan for viruses and adware

Open Windows Security → Virus & threat protection and run a Full scan. It can take an hour, so run it when you do not need the laptop. Be wary of "PC cleaner" or "speed booster" programs that pop up warnings and ask you to pay. They are often the reason the laptop is slow in the first place.

8. Know when it is the hardware

If you have done all of the above and the laptop is still slow, the cause is usually one of these:

  • An old hard drive (HDD). In Task Manager, open Performance → Disk. If it says HDD rather than SSD, replacing it with an SSD is the single biggest speed upgrade for an older laptop. Your files and Windows can be moved across.
  • Not enough memory. With 4 GB of RAM, Windows 11 and a web browser will struggle. Many laptops can take more.
  • Overheating. If the fan is loud and the bottom is hot, dust may be blocking the vents, and the processor slows itself down to cool off. Use it on a hard surface, not a bed or a blanket.

An SSD or a RAM upgrade usually costs far less than a new laptop and can give an older machine a few more good years.
